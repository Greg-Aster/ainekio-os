# Computer Tasks and Approvals

Agent Mode delegates commands through the existing Full Task Delegation node to
the configured Big Brother provider. Core's escalation backend and Terminal own
native tool execution and process sessions. The local skill implementations and
their separate approval queue have been retired.

The same native task node supplies capability metadata to Agency's existing tool
catalog. Plan generation and validation use that catalog; they do not register or
execute a second set of local skills.

Review Desire plans in **Agency** or the approval controls in Chat. These use
Agency's existing policy and lifecycle owners. The separate operator-proposal
card, stream and APIs are retired; stored proposal and feedback history remains.
Shared trust settings still apply through their current policy consumers.

A provider result reports what the provider returned. Approval authorizes work;
it does not prove execution or an external outcome. Check the reported result,
changed artifact, or physical observation appropriate to the task.

Existing approval history is preserved. This cleanup does not replay legacy
requests or migrate them into Agency.
